# docx2md — Конвертер Word в Markdown

Данный Docker-образ позволяет конвертировать документы Microsoft Word (.doc и .docx) в формат Markdown.

## Запуск веб-сервиса

```
docker run -d -p 8000:8000 --name docx2md victorkozmin/docx2md
```

Порт можно изменить через переменную окружения PORT:

```
docker run -d -p 8080:8080 -e PORT=8080 victorkozmin/docx2md
```

После запуска сервис доступен по адресу http://localhost:8000

## Использование через API

Отправьте POST-запрос на /convert с файлом (multipart/form-data, поле file).

Пример с curl:

```
curl -F "file=@документ.docx" http://localhost:8000/convert
```

Ответ (JSON) содержит поле markdown с готовым текстом.

## Использование CLI внутри контейнера

Если нужно преобразовать файл напрямую, смонтируйте папку с документами:

```
docker run --rm -v $(pwd):/data victorkozmin/docx2md python -m app.cli /data/документ.docx -o /data/результат.md
```

## Поддерживаемые возможности

- Заголовки (по стилям Word или по форматированию: жирность + размер шрифта)
- Маркированные и нумерованные списки (с отступами)
- Таблицы (упрощённо, с сохранением порядка)
- Сноски (сквозная нумерация, выносятся в конец)
- Изображения заменяются на [Изображение] (с подписью, если есть)
- Спецсимволы Markdown экранируются
- Выходная кодировка — UTF-8
