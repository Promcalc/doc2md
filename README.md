# DOCX/DOC to Markdown Converter

Конвертирует документы Word (.doc, .docx) в Markdown с поддержкой:
- Заголовков по стилям (Заголовок 1, 2, ...)
- Списков (маркированных и нумерованных) с отступами по 2 пробела
- Таблиц (упрощённо, без сложных объединений)
- Сносок (сквозная нумерация, все в конце)
- Замена изображений на `[Изображение]` или `[Изображение: описание]`
- Экранирование спецсимволов Markdown
- Кодировка UTF-8

## Сборка образа

```bash
docker build -t docx2md .
```

## Запуск сервиса
```bash
docker run -d -p 8000:8000 --name docx2md docx2md
```

Порт можно изменить через переменную окружения PORT:

```bash
docker run -d -p 8080:8080 -e PORT=8080 docx2md
```

## Использование через API
Отправьте POST-запрос на /convert с файлом (multipart/form-data, поле file):

```bash
curl -F "file=@document.docx" http://localhost:8000/convert
```
Ответ: JSON с полем markdown, содержащим текст в формате Markdown.

## Использование CLI внутри контейнера
```bash
docker run --rm -v $(pwd):/data docx2md python -m app.cli /data/input.docx -o /data/output.md
```
Или запустите интерактивно:

```bash
docker run -it --rm -v $(pwd):/data docx2md bash
python -m app.cli /data/input.docx
```

### Ограничения
Таблицы с объединёнными ячейками обрабатываются упрощённо: содержимое дублируется, а вертикальные объединения игнорируются (заполняются пробелами).

Поддерживается только базовая структура документа; сложные макеты могут давать неидеальный результат.
